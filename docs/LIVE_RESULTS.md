# 真实模型实验：提交前复核是否值得

日期：2026-10-06。这页只统计冻结版本的真实 DeepSeek + Docker 实验。
早期探索、短文本 probe、自由 ask 和离线故障注入都不并入准确率。

## 设置与可比性

- 运行逻辑冻结：`1f52a5046aceb424175d40cdd3ad3ecb1ff16c67`；13 个模块的
  文本快照哈希见公开 provenance。后续 CI/文档改动不影响运行逻辑。
- 模型别名 `deepseek-flash`；temperature=0、非思考模式、max_tokens=2048，
  timeout=60 秒、keepalive=120 秒，SDK 重试为 0。
- 两策略最多各 6 次请求；task/repeat 按 seed=0 打乱，相邻配对，交替先后。
  上限相同不代表实际计算量相同；没有跨题共享上下文或记忆。
- dev：种子 7/23/91；holdout：101/211/307。各 12 题、每题 3 次、每策略
  36 次尝试。同一 CSV 的四个问题和同题重复不是独立的新数据集样本。
- 标准答案由 Decimal 计算，只在交卷后评分；容器不挂载答案、源码或 Key。
  数值绝对容差 0.01；JSON 类型和纯 JSON 提交契约未放宽。
- 本机 Ubuntu 24.04.5 / Python 3.12.3 / openai 3.13.0 / Docker Engine
  29.8.2；WSL 内核 `6.18.40.1-microsoft-standard-WSL2`。
  实测镜像 ID `sha256:6b1f85a08c199d29d5b6d71ab9c27bd5b3b393492e01216a15758ff69c4be8b8`。
  程序仍引用可变标签，不宣称已经实现不可变镜像锁定。

## 能得出什么，不能得出什么

dev 未观察到复核收益，holdout 出现一次预算退化，计算成本明确增加。保留 baseline 为真实入口
默认策略，verify 作为实验选项。不能把 100% 写成通用 Agent 能力或自我学习。
这一小型合成任务集存在天花板效应；没有统计显著性或跨领域泛化结论。

早期开发真实失败包含 API ConnectTimeout、数字字符串和 JSON 外附加说明。
它们指导了连接配置与公开提交协议的修正，记录完整保留；探索性中断批次不
与正式成绩混合，也不把开发前后变化宣称为独立的因果实验。

下一轮应先建立独立、可确定评分的挑战开发集，检查复杂筛选、连接、单位与
执行错误，再测试预算感知的复核/交卷调度与计算量对照。已有题集不够难时，不为获得提升
临时污染 holdout，更不以 memory、SFT 或 RL 的功能名称替代证据。
